# phanquan-guitars

Frontend website: React, Vite, JavaScript, Tailwind CSS, and React Router.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually [http://localhost:5173](http://localhost:5173)).

## Layout

- `index.html` — HTML entry
- `src/main.jsx` — React mount + router
- `src/App.jsx` — routes
- `src/index.css` — Tailwind
- `vite.config.js` — Vite, React, and Tailwind plugins
